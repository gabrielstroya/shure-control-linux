# Security and privacy

This is experimental local desktop software, without a security support SLA.
Do not run the GUI as root. Use only the model-specific MV7 HID rule and retain
its active-session ACL restrictions.

Do not post credentials, voice recordings, full hardware backups, serial numbers,
private paths or unreviewed diagnostic exports in public issues. A useful bug
report contains versions, reproduction steps, a sanitized error and whether the
result was simulated or observed on physical hardware.

For a potential vulnerability, prefer GitHub's private vulnerability reporting
if the repository offers it. If it is unavailable, open a minimal issue asking
for a private contact route without including exploit details or private data.
There is no application telemetry or automatic submission of logs.
